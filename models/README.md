# Models

Notebook `02_Autoencoder_Training.ipynb` saves the trained Keras autoencoder here as:

```text
models/iot_autoencoder.keras
```

It also saves the normalization parameters and anomaly threshold as:

```text
models/scaler.json
models/threshold.json
```

These files are generated locally after training and are not required in the source repository before the notebooks are run.
