# Contributing

Thanks for considering a contribution to this project.

## Simple Workflow

1. Fork the repository.
2. Create a branch for your change.
3. Keep the repository structure simple.
4. Do not add a `src/` directory or separate preprocessing/helper modules.
5. Keep notebook explanations clear and reproducible.
6. Test the Flask application before opening a pull request.
7. Update `CHANGELOG.md` when your change affects project behavior.
8. Open a pull request with a short explanation of what changed.

## Code Style

Prefer straightforward Python that is easy for a student or interviewer to read. Avoid unnecessary abstractions for small pieces of logic.

## Notebook Contributions

Notebook cells should be ordered logically and should run from top to bottom on a clean environment.
