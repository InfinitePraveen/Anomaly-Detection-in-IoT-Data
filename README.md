# Anomaly Detection in IoT Data

A practical deep-learning project that detects unusual IoT sensor behavior using a reconstruction autoencoder built with Keras. The project uses the **Numenta Anomaly Benchmark (NAB)** time-series data as an open-source benchmark and presents the model through a small Flask web application.

## Project Overview

IoT devices continuously generate measurements such as temperature, pressure, vibration, voltage and network statistics. A sudden change may indicate a faulty sensor, equipment problem, or unusual operating condition.

This project learns the normal pattern of a sensor signal with an autoencoder. The model is trained mostly on normal behavior. When a new time window is difficult to reconstruct, its reconstruction error becomes high and the window is marked as an anomaly.

## Dataset

The notebooks use the open-source **Numenta Anomaly Benchmark (NAB)**. The benchmark contains timestamped time-series data with labeled anomalous behavior. For this project, the notebooks use:

- `art_daily_small_noise.csv` for normal training behavior
- `art_daily_jumpsup.csv` for anomaly testing

The dataset is downloaded directly from the NAB GitHub repository by the notebooks, so large source data files do not need to be committed to this repository.

Dataset source: https://github.com/numenta/NAB

## How the Model Works

```text
Sensor readings
      ↓
Normalization
      ↓
Sliding time windows
      ↓
Encoder
      ↓
Latent representation
      ↓
Decoder
      ↓
Reconstructed window
      ↓
Reconstruction error
      ↓
Error > threshold?
   ↙          ↘
 ANOMALY      NORMAL
```

The model is not trained as a conventional classifier. Instead, it learns to reconstruct normal sequences. A high reconstruction error indicates that the observed pattern differs from what the model learned.

## Setup

Python **3.12** is recommended for this repository.

Create a virtual environment:

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Install dependencies:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Run the Notebooks

Start Jupyter:

```bash
jupyter notebook
```

Run the notebooks in this order:

1. `01_Data_Exploration.ipynb` — download and understand the sensor data.
2. `02_Autoencoder_Training.ipynb` — create sequences, train the Keras autoencoder and save the trained model.
3. `03_Anomaly_Evaluation.ipynb` — calculate reconstruction errors, choose a threshold and evaluate detected anomalies.

The training notebook saves the trained model and threshold inside the `models/` directory.

## Run the Flask Web App

After completing notebook 2, run:

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```

The web app allows an interviewer to enter a sensor reading window and see:

- anomaly status
- reconstruction error
- detection threshold
- simple explanation of the result

## Interview Demonstration

A good interview demonstration is:

1. Explain why anomaly detection is useful in IoT.
2. Show the normal and anomalous time series in notebook 1.
3. Explain the encoder and decoder architecture.
4. Show training loss and reconstruction examples.
5. Explain why reconstruction error can be used as an anomaly score.
6. Show the selected threshold.
7. Open the Flask app.
8. Enter a normal sequence and show a low reconstruction error.
9. Enter an unusual sequence and show the anomaly warning.

## Important Note About the Web App

The Flask app expects the trained Keras model and threshold generated by notebook 2. This keeps the repository simple and avoids adding separate preprocessing or model-service modules.
